# 本地复核与远端结果对比

## 一、本地复核方式

本次使用最终冻结包中的本地策略脚本重新运行：

```text
plot_local_three_state_strategy.py
```

输入为：

- 本地现货研究面板：`01_报告资料与基础上传包/统计表/panel.csv`；
- 冻结八列表参考：`最终执行日简表_零段反转冻结参考.csv`；
- 基础策略：实际执行日的基础三状态乘以执行日收盘到收盘收益；
- 调整策略：加入四个反转信号，0转-1按3个交易日、0转+1按5个交易日展开，并执行基础状态覆盖和反向冲突归零。

本地策略脚本的净值口径是：


\[
NAV_t=1+\sum_{s\leq t}(state_s\times C2C_s)
\]

因此，本地复核主要用于判断结果方向和结构是否一致，不把本地数值与远端截图中的每一个收益数字机械地当成同一口径。

## 二、本地总体结果

本地可用数据为 2018-01-03 至 2026-08-14，共2090个执行日。

| 指标 | 原始三状态 | 加入四个反转 | CSI500买入持有 |
|---|---:|---:|---:|
| 最终净值 | 2.3658 | 3.4534 | 1.4477 |
| 总收益 | +136.58% | +245.34% | +44.77% |
| 年化收益 | +10.52% | +15.48% | +4.39% |
| 年化波动率 | 14.36% | 16.60% | 22.75% |
| 夏普比率 | 1.15 | 1.78 | 0.24 |
| 最大回撤 | -11.62% | -8.80% | -44.26% |
| 方向持有日数 | 639 | 1035 | 2090 |
| 持有日胜率 | 54.15% | 53.53% | 51.48% |
| 持有日平均方向收益 | +21.37bp | +23.70bp | +2.14bp |

本地结果与远端截图的共同结论是：

- 加入四个反转后总收益明显高于原始三状态；
- 夏普比率提高；
- 最大回撤改善；
- 方向持有日数明显增加；
- 调整策略明显高于指数买入持有。

但并不是每一个指标都单调改善：本地调整策略的持有日胜率从54.15%下降到53.53%，说明收益改善主要来自增加了有效持有日以及持有日平均收益提高，而不是简单地把每个信号的命中率都提高。

## 四、与远端截图的差异

远端截图汇总为：原始总收益 +143.76%，调整后 +283.16%；本地复核为：原始 +136.58%，调整后 +245.34%。两者方向一致，但数值不同，原因主要有：

1. 本地数据截止到2026-08-14；远端年度汇总包含更多交易日，远端总日数为2094天，之前终端截图还出现过更新到更晚日期的2096行版本。
2. 本地策略脚本使用执行日收盘到收盘收益和线性累加净值；远端汇总的具体收益实现需要以远端运行脚本和逐日输出为最终口径。
3. 本地复核使用冻结八列表参考和固定3/5日持有展开；如果远端运行使用的是完整冻结持有路径中的释放阈值、最大持有和冷却状态机，持有日数和收益会产生差异。

因此，当前可以确认的是“结论一致”，还不能仅凭截图声称“逐日收益数值完全一致”。要做到数值逐日一致，需要使用同一个现货文件、同一个截止日期、同一个执行日收益公式和同一份远端八列表逐行对齐。

## 五、合理性判断

本地复核支持远端结果具有合理性：

- 原始策略本地和远端都明显跑赢指数；
- 加入反转后本地和远端都进一步提高净值和风险收益比；
- 反转信号增加的是方向持有覆盖，而不是只改变某几个事件日；
- 个别年份（本地2020、2023）调整后反而略差，说明结果不是机械地对所有年份做正向修饰；
- 本地与远端的计数口径也已对上：`0转-1=322`、`0转+1=390`、`+1反转=62`、`-1反转=45`。

最终判断：

> 远端结果的方向和本地独立复核一致，可以认为整体逻辑合理。调整后的大幅提升具有本地复现支持，但由于收益口径和截止日期尚未完全统一，正式汇报时应引用远端逐日文件或统一口径后重新计算，不应把两套收益数字直接拼接使用。
