# 20260824_1325｜冻结中证500输出包

这是一个独立的远端运行包，包含当前冻结的 01—06 全部逻辑，并新增 07 作为“远端结果 vs 本地结果”专门一致性检查。01—06 的计算逻辑保持不变，只把包根目录、现货输入和前序输出改成远端绝对路径。

远端运行时，生产计算只需要一份中证500原始现货日频文件；本地结果已经作为 `本地结果对照/` 放入包内，不需要再从本地电脑读取，也不需要读取远端三状态文件才能生成信号。

## 包内入口

- `01_只用远端现货生成八列.ipynb`：只用远端现货生成事件型精简八列；
- `02_八列表详细一致性检查.ipynb`：保留原有八列表冻结参考检查；如显式设置 `REMOTE_THREE_STATE_PATH`，也可以追加独立三状态文件检查；
- `03_含持有期零段反转八列表.ipynb`：重新生成 01 的冻结八列，并展开 V38/V57 的冻结持有路径，得到每日含持有期精简八列；
- `04_O2O加算收益与持有段计数分析.ipynb`：读取 03，生成 O2O 加算收益、净值、风险和持有段统计；
- `05_逐年分析与2026表现解释.ipynb`：读取 04，生成逐年、训练/验证/测试期及 2026 拆解；
- `06_历史相似行情与机制分解分析.ipynb`：读取同一份远端现货、03 和 04 的远端输出，生成历史相似行情及机制分析；
- `07_远端与本地结果一致性检查.ipynb`：将远端本次运行的 01、03、04、05、06 表格与包内 `本地结果对照/` 逐表、逐行、逐列比较，输出明确的 `success` 结论。

生产冻结代码在 `src/` 和 `packages/` 中；不包含候选扫描、成交记录、未来评价记录或每日现货快照。

## 每日应该运行什么

如果你的目标只是“更新当天最新的含持有期精简八列”，每天只需要运行：

```text
03_含持有期零段反转八列表.ipynb
```

03 会先调用冻结的 01 生产入口重新生成原始事件八列，再按 H03/H04 展开 `0转-1`、`0转+1` 的冻结持有路径，输出：

```text
/home/hzy/cta/20260824_1325_冻结中证500输出包/runtime_outputs_holding_period/含持有期八列表.csv
```

03 目录下还会保留它本次调用 01 生成的中间事件八列：

```text
/home/hzy/cta/20260824_1325_冻结中证500输出包/runtime_outputs_holding_period/最终执行日简表.csv
```

如果需要单独更新标准 01 输出目录下的事件八列，则运行 `01_只用远端现货生成八列.ipynb`，其输出是：

```text
/home/hzy/cta/20260824_1325_冻结中证500输出包/runtime_outputs/最终执行日简表.csv
```

因此，日常最简流程是：

```text
03 → 得到最新含持有期精简八列
```

如果还要更新分析结果，则按下面顺序运行：

```text
01 → 02（可选检查）→ 03 → 04 → 05 → 06 → 07
```

其中 07 必须放在 01、03、04、05、06 都完成之后运行；它只检查结果，不参与任何信号生成。

## 输出列和日期口径

01、03 的精简八列固定为：

```text
实际执行日、三状态、+1反转、-1反转、0转-1、0转+1、大涨、大跌
```

每一行统一遵循：

```text
t 日收盘形成信号 → 下一实际交易日 t+1 开盘执行
```

最新形成日的信号值由最新现货收盘前可获得的数据真实计算，不用 0 占位；如果最新执行日尚无下一日开盘价，只影响收益评价，不影响信号输出。

## 本地结果对照

`本地结果对照/` 是已经用本地米筐现货生成的固定参考，不是远端运行输入：

- `01_只用现货生成八列/最终执行日简表.csv`：本地事件八列；
- `03_含持有期零段反转八列表/含持有期八列表.csv`：本地含持有期八列；
- `04_O2O加算收益与持有段计数分析/`：本地 O2O、风险和持有段结果；
- `05_逐年分析与2026表现解释/`：本地逐年及 2026 结果；
- `06_历史相似行情与机制分解分析/tables/`：本地机制分析表；
- `现货快照元数据.json`：本地参考的现货日期范围和文件摘要信息。

本地参考现货截至 2026-08-21，对应最新执行日为 2026-08-24。远端若使用不同更新日期，07 会明确报告日期集合不同，不会把不同截点误报为一致。

## 07 一致性检查内容

07 比较以下结果：

1. 远端 `runtime_outputs/最终执行日简表.csv` vs 本地事件八列；
2. 远端 `runtime_outputs_holding_period/含持有期八列表.csv` vs 本地含持有期八列；
3. 远端 04 的核心 CSV vs 本地 04 对照表；
4. 远端 05 的核心年度/2026 CSV vs 本地 05 对照表；
5. 远端 06 的核心机制表 vs 本地 06 对照表。

结果写入：

```text
/home/hzy/cta/20260824_1325_冻结中证500输出包/runtime_outputs_07_consistency/
```

重点文件：

```text
一致性检查摘要.csv
一致性检查结论.json
不一致明细_*.csv
```

只有所有参与比较的表格日期、列名、行数和数值都通过，`一致性检查结论.json` 中的 `success` 才为 `true`。没有对应远端输出或日期截点不同，会明确标记为失败/不适用，不会伪造一致。
