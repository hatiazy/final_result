# final_result

这是四个冻结信号研究、汇报和运行材料的整理版。根目录按用途分组；汇报材料统一放在一个目录下，四类最终大候选池冻结上传包也统一放在一个正式目录下。

## 先看哪里

当前最终汇报：

[基础三状态、非零退出与大涨大跌离线汇报](03_汇报版本/20260818_1024_05汇报_基础三状态非零退出大涨大跌版/基础三状态_非零退出_大涨大跌_离线互动汇报.html)

汇报版本索引：[03_汇报版本/README.md](03_汇报版本/README.md)

日常更新六列表：进入 `04_最终大候选池冻结上传包/01_基础三状态与统一六列运行`，运行其中的 `01_只用远端现货生成六列.ipynb`；需要做本地逐日核对时，再运行 `02_六列表详细一致性检查.ipynb`。

## 目录

| 目录 | 用途 |
|---|---|
| `01_报告资料与基础上传包` | 原始研究数据、统计表、历史九列基线和审计记录 |
| `02_HTML生成工具` | 四信号合并、统计和报告构建工具 |
| `03_汇报版本` | 按时间排列的四个汇报版本；当前版本是 `20260818_1024` |
| `04_最终大候选池冻结上传包` | 基础三状态、长0、1545涨跌反转、大涨大跌的统一最终入口 |
| `05_上传包_日期解析修正版` | 历史冻结验证工程包和远端逐日一致性检查 |
| `99_中间归档` | 0817 中间测试输出和旧索引，仅用于追溯，不作为日常入口 |

## 汇报版本

`03_汇报版本` 内的每个时间目录都是一个完整版本：

- `20260811_1535`：历史展示版；
- `20260817_1628`：基础四信号合并版；
- `20260817_1657`：非零退出与四信号完整中间版；
- `20260818_1024`：当前最终汇报版。

新增汇报时，只在 `03_汇报版本` 下增加一个新的时间版本目录，不再复制出新的 `03`、`04`、`05` 汇报目录，也不再在里面嵌套另一个总目录。

## 清理规则

缓存、`.DS_Store`、Python 字节码、Jupyter 检查点和运行日志不纳入项目；`.gitignore` 已统一忽略这些文件。
