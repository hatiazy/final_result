# 中证500基础三状态与四个反转信号：构建逻辑、冻结边界与老师问题汇报

日期：2026-08-24
说明：本报告只解释当前最终冻结运行包，不修改既有代码、阈值、参数、输出格式或日期口径。正文中的图片已经复制到本报告目录并直接展示。

## 一、先给结论

### 1. 老师的问题现在能不能回答

可以回答大部分，而且现有远端图已经能支持一个有边界的解释：

- 红色区间的 0 状态多，主要是基础三状态刻意要求多视角一致、入口阈值和连续确认；小幅、分歧的行情可能仍然属于“未确认”，不等于完全没有方向积累。
- 四个反转信号不是把基础三状态重新训练一遍，而是叠加在基础三状态上的退出/零段转移事件层；其中 0→-1 和 0→+1 默认是事件列，不是自动延续的连续状态。
- 2026 年识别较快，现有图支持“行情变化更集中、多个视角同时变化、滚动相对标准化和固定确认规则共同作用”的机制解释；但若要精确拆分三者各贡献多少，还需要额外的反事实对照图。此次不改变冻结逻辑，所以只做定性归因，不把它夸大成唯一因果结论。

### 2. 当前研究可以如何定性

当前中证500的研究可以先确定为：

- 基础三状态：中证500的长周期市场阶段基线；
- V55、V80：原方向状态的退出提醒；
- V38、V57：0 状态中的稀疏方向转移事件；
- 下一步：在保持严格形成日/执行日口径的前提下，单独做一日快速反应预测。

四个反转信号有用，但角色不是相同的预测器。V38 的开发、验证和测试方向证据相对更稳定；V57 通过冻结门槛并可运行，但证据弱于 V38。V55/V80 更适合作为长周期状态的退出覆盖层，而不是独立替代三状态。

## 三、完整每日计算链

### 3.1 每日唯一生产输入

生产入口只读取一份中证500现货日频表：

| 数据 | 用途 |
|---|---|
| 交易日 | 形成日排序和下一实际执行日 |
| open | O2O 执行价格 |
| high、low | 日内区间和波动 |
| close | 收益、趋势、方向轴 |
| volume、amount | 成交量和量价证据 |
| prev_close/preclose | 跳空与前收；缺失时由历史 close 得到 |

生产运行不读取本地旧六列表、八列表、候选池结果、未来评价记录、期货/持仓量/基差或测试集收益。

### 3.2 日期口径

设形成日为 t：

1. t 日收盘后，用 t 日及以前的现货数据计算八状态、三状态和四个反转信号；
2. 该行映射到下一实际现货交易日 t+1；
3. t+1 日开盘执行；
4. 历史评价中的 O2O_H1 才会再使用 t+2 日开盘。

因此输出表中的“执行日”对应的值，确实是上一个实际交易日收盘计算出来的，不是用执行日当天数据倒推。如果输入最新一行还没有下一实际现货行，运行包只给出下一工作日的执行日期标签，信号数值仍然来自最新形成日的真实计算，不会先填0再补。

### 3.3 基础三状态

每天先从现货重算八个连续状态：

1. 位置修复；
2. 跳空/日内承接；
3. 趋势；
4. 量价；
5. 路径脆弱；
6. 尾部压力/波动切换；
7. 反转压力；
8. 过热。

冻结配方按需要使用原始因子或滚动 z-score。滚动 z-score 的统计量使用 stats_lag=1；随后各因子用历史因果滚动分位数转换为 0 到 1 的相对强度。八状态的主要因果滚动窗口为504个交易日，至少需要252个有效历史观测；状态输出从2018年开始。保留更早现货只是为了预热，不代表更早历史被当成测试结果。

四个主要方向视角先形成两个引擎：

~~~text
慢引擎 = (趋势状态 + 量价状态) / 2
快引擎 = (位置修复状态 + 跳空/日内承接状态) / 2
~~~

1545 的方向轴为：

~~~text
continuous =
    0.40 × 趋势
  + 0.30 × 量价
  + 0.15 × 位置修复
  + 0.15 × 跳空/日内承接

band =
    0.40 × 趋势等级
  + 0.30 × 量价等级
  + 0.15 × 位置等级
  + 0.15 × 日内等级

direction_axis = 0.70 × continuous + 0.30 × band
~~~

随后应用冻结的 1545 状态机：

- 下行入口主要要求方向轴不高于0.30、慢快引擎共同偏弱、低位视角数量足够，且不存在反弹/长期正向否决；
- 上行入口主要要求趋势和量价达到0.70、位置和日内承接至少达到0.42、方向轴达到0.70，且没有过热/反转退出否决；
- 普通上下行入口需要连续确认2天；
- 强方向状态最小驻留约5天；
- 中性状态最小驻留约2天；
- 0.42和0.58是滞回带，防止状态被单日噪声来回打断。

所以三状态不是“固定涨跌幅阈值模型”，也不是每天重选0.30/0.70；它是对每天重新计算的滚动相对状态值应用固定的长周期状态机。

## 四、四个反转信号的构建和阈值

| 信号 | 当前基础状态 | 最终评分与冻结阈值 | 运行条件 | 角色 |
|---|---|---|---|---|
| -1→0，V55 | -1，状态年龄至少1 | score_02；Dev 68%分位，0.815842643776842；确认2天 | 负向状态内评分持续达到阈值 | 负向退出提醒 |
| +1→0，V80 | +1，状态年龄至少5 | score_02；Dev 90%分位，0.4920211306764882；确认1天 | 正向状态内评分达到阈值 | 正向退出提醒 |
| 0→-1，V38 | 0，零状态年龄至少1 | score_01；V38 window=4、方向滞后1；Dev 85%分位，1.2294466376933055；确认1天 | 成交量异常与价格方向共振 | 零段向下事件 |
| 0→+1，V57 | 0，零状态年龄至少1 | score_01；RQA m=2、delay=2；Dev 85%分位，4.671980676328502；确认1天 | 递归路径重复结构与向上方向共振 | 零段向上事件 |

阈值来源不是每天重新估计：

- V55/V80 的阈值来自 Development 内对应非零状态、状态年龄达标、分数有效且历史 H1 已成熟的分数分布；
- V38/V57 的进入阈值来自 Development 内可选零状态的分数分布；
- Validation 用来做跨阶段质量检查；
- Test 从2025年开始只在候选冻结后观察。

V55 的 score_02 是 Development 校准的归纳保序鞅分数；V80 的 score_02 是15日 catch22 风格动力学特征分类器，分类器只在 Development 用方向化 O2O_H1 标签训练。V38 是成交量滚动异常与近端价格方向的乘积；V57 是约80日 RQA 路径确定性并用最近收益方向定向。四者在最新形成日都只使用当天及以前的现货特征。

V38 的持有审计包是 H03：最短3日、最长10日、释放阈值0.6645986031220402、冷却3日。V57 的持有审计包是 H04：最短5日、最长20日、释放阈值4.606280193236715、冷却5日。正式八列表默认保留事件日列；含持有期 Notebook 才把冻结 holding_path 展开用于持有质量和红色区间解释。

## 五、冻结筛选是否使用了测试集

没有。四个信号的冻结隔离如下：

| 层次 | Development | Validation | Test |
|---|---|---|---|
| 基础三状态 | 筛选状态机和特征配方 | 检查跨阶段语义和驻留 | 冻结后观察 |
| V55/V80 | 训练/校准、候选评价和阈值 | 独立评价 | 冻结后观察 |
| V38/V57 | 候选网格、Dev阈值、事件质量和持有质量 | 独立质量门和最终选择 | 冻结后观察 |

V38/V57 的候选评价不只看一日收益，还看 H1/H3、命中率、Rank IC、目标状态转移率、转移纯度、相对全部可选零状态的 lift、持有段收益和持有段胜率。V57 的证据弱于 V38，主要体现在事件 Rank IC 接近0，测试 Rank IC 还转为负，事件数量也较少；它是“通过门槛、可以运行、但要保守表述”，不是“与 V38 同等强”。

## 十、最终给老师的回答

可以这样概括：

本报告不把四个反转信号说成同等强度，也不把测试集表现倒推为冻结依据。当前最稳妥的定性是：
