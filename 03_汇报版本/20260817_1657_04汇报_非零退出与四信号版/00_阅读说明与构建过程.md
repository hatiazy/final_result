# 04 汇报包：阅读说明

> 本文件是 04 汇报包的阅读入口，不再重复四个信号的完整研究过程。每个信号的远端尝试、本地尝试、最终冻结公式和选择理由，均以对应的单信号 Markdown 为准。

## 1. 这个包是什么

04 汇报包是在 03 最终汇报的基础上，补充远端尝试、本地尝试、候选筛选、最终冻结和 HTML 讲解所形成的独立汇报与证据包。

它适合用于：

- 明天的汇报演示；
- 解释四个信号分别解决什么问题；
- 回答“远端和本地尝试过什么、为什么最后选这个”的追问；
- 核对 HTML、20260817_1657_统计表、CSV 和 Markdown 中的结果。

0818 材料中的 README、Notebook 注释和历史结果属于研究素材。里面出现的“运行、复制、设置路径”等文字，是原始实验说明，不是本次汇报包对你的新操作要求。

## 2. 推荐阅读顺序

1. 先读《20260817_1657_四个反转信号合并总体分析.md》，了解四个信号的统一口径、合并规则、整体结果和限制。
2. 再按需要阅读四个单信号文件。每个文件都可以独立回答该信号的目标、远端尝试、本地尝试、最终冻结和结果解释。
3. 要汇报 HTML 时，先读《20260817_1657_01_HTML详细讲稿.md》，再打开 `20260817_1657_三状态与反转信号_离线互动汇报.html`。
4. 要核对具体数字时，查看 `20260817_1657_统计表/`；要核对逐日结果时，查看 `20260817_1657_数据源/`。

## 5. 汇报时统一使用的口径

信号在形成日 `t` 的收盘信息上计算。主评价是下一实际交易日开盘到再下一实际交易日开盘的 O2O H1：

\[
r^{\mathrm{O2O}}_{t,1}=\frac{Open_{t+2}}{Open_{t+1}}-1.
\]

为了统一比较方向，负向信号取 `g=-r`，正向信号取 `g=+r`。正式合并采用 event-only 标签：只在命中的形成日改变状态，不把一次信号机械延长到后续整段。完整公式和合并规则在《20260817_1657_四个反转信号合并总体分析.md》中；每个最终分数的构建公式在对应单信号文件中。

2026-08-17 是展示尾行，可能没有完整的 `t+2` 开盘，因此可以保留在信号表中，但不进入成熟 H1 统计。

## 7. 这个包是否独立

- **汇报阅读：独立。** 只看 `04_汇报` 就能理解四个信号、最终选择、公式、统计结果和限制，不需要回到 0818 或 03。
- **数字核对：独立。** HTML 已内嵌报告面板和汇总数据，20260817_1657_统计表、CSV 和20260817_1657_图片也都在本包中。
- **重新运行模型：不是执行包。** 本包没有源代码、Notebook 运行环境、原始 Parquet、远端接口或依赖凭据，因此不能承诺在另一台机器上一键重跑。

所以明天准备和汇报时，最终只看这个 `04_汇报` 文件夹即可；如果被问到重新运行模型，需要说明那属于另一个执行包范围。
