# 零段向下（0→-1）｜独立详细分析

本报告只分析一个信号，数据来自最新本地重跑的最终上传包口径。所有收益使用 effective-date 网格上的 CSI500 下一交易日开盘到再下一交易日开盘（O2O H1），不把 C2C 当作冻结评价指标。

## 1. 信号定义与结论

- 来源：长0两侧转移预测；冻结规则：`V38 / volume breakout`。
- 作用：从中性进入负向；要求信号发生时基础状态为 `0`。
- 事件口径：零段转移只在当天把基础 0 改成 -1/+1；后续 0 日不延续重标，同日双向冲突保持 0。
- 本信号的判断：**有较明确的正向证据**。

全周期有效事件 136 天，覆盖符合条件的基础状态 1452 天中的 9.37%；可计算 H1 的事件 136 天。信号日方向化/退出改善均值 **27.43 bp**，bootstrap 95% 区间 **[3.09, 52.64] bp**；相对所有符合条件基础日均值 0.18 bp，差值为 **27.24 bp**。

## 6. 最终判断

综合本信号的事件均值、相对条件基础日提升、不同阶段稳定性、前向 1/3/5/10 日路径以及原始段位置，本信号的证据强度判断为：**有较明确的正向证据**。最重要的限制是事件样本不是独立同分布的：连续信号日会集中在同一段行情，且最近一个有效期末日可能没有完整未来 O2O 观察。因此，本报告支持‘是否有描述性改善’的判断，不支持把历史均值解释成未来收益保证。

## 附录：远端尝试、本地尝试与最终构建

### 1. 要解决的具体问题

本信号只在基础状态 `0` 中寻找进入负向状态的事件。形成日 `t` 的目标方向收益为：

\[
r^{O2O}_{t,1}=\frac{Open_{t+2}}{Open_{t+1}}-1,
\qquad
g_t=-r^{O2O}_{t,1}.
\]

只有 `B_t=0` 且下侧事件命中时，正式 event-only 状态当天才写成 `-1`；之后没有新事件的零状态仍写 0。这样测的是“进入日是否有方向优势”，而不是把一次事件当成持仓持续信号。

### 2. 远端尝试做过什么

长 0 远端线依次尝试了 V1、V2、V2.1 和 V2.2：

- V1 将原来的统一转移控制器拆成下、上两侧，保留规则距离收窄、快慢引擎、方向视图、轨迹确认、零龄和证据收敛；候选约 `5,760` 条/侧。
- V2 使用单侧 L2 Logistic 探针，同时预测 H1 方向并把 H3 作为诊断；它是对连续信号排序的探测，不把概率当成真实概率。
- V2.1 发现概率不单调、方向排序不稳定，于是删掉 H3/快速恢复/rank IC 硬门，改看 H1 方向和错误幅度尾部，用 Development 的零日 O2O 绝对收益 P75 定义 adverse cutoff。
- V2.2 进一步改成低频安全事件：单个零段只出一个事件脉冲，加入冷却、覆盖率和实际持仓结构限制，防止信号太密、快速恢复和大量一天段。

这些版本没有直接成为当前四信号中的 V38，但它们解决了两个重要问题：不能把概率头的高分当成稳定方向；入口信号必须同时检查覆盖率、转移纯度和实际持仓段结构。

### 3. 本地做过什么

本地长 0 线对 V01–V120 可执行逻辑和 V121–V150 实验逻辑统一审计。标准候选网格为：

\[
16\text{ 个核心变体}\times4\text{ 个最小零龄}\times8\text{ 个入口分位}\times3\text{ 个确认日}\times4\text{ 个持仓包}=6,144.
\]

本地修正了因果百分位、稳健尺度和实验版滚动统计，并设置 Dev/Val 的样本数、H1/H3 方向、H1 胜率、转移 lift/纯度、零段长度、一天段占比、实际持仓段胜率和快速恢复等质量门。严格筛选后，下侧只有 V38 进入最终池；上侧另行筛选 V57，双方不共享阈值。

### 4. V38 最终分数怎样构建

V38 的核心思想是“成交量异常必须和价格方向共振”，不是单纯看到放量就触发。对 `Volume_t` 取对数并在过去窗口 `w` 内标准化：

\[
v_t=\log(1+Volume_t),
\qquad
z^{vol}_{t,w}=\frac{v_t-\operatorname{mean}_w(v)}{\operatorname{std}_w(v)}.
\]

价格方向用过去约 `w/4` 的收盘对数变化：

\[
d_{t,w}=\operatorname{sign}\left(\log Close_t-\log Close_{t-\max(1,\lfloor w/4\rfloor)}\right).
\]

原始方向分数为：

\[
S^{V38}_t=z^{vol}_{t,w}\cdot d_{t,w}.
\]

下侧候选再按侧别定向，使较大的分数支持 `0→-1`。最终冻结候选为：

```text
V38_down_s01_a1_q0.85_c1_H03
score variant=s01；最小零龄=1；入口分位=0.85；确认=1天；持仓包=H03
```

### 5. 为什么选它，以及怎样表述结果

V38 在当前 03 口径下有 136 个事件日、条件零状态日 1,452 个，方向化 O2O H1 为 27.43 bp，95% bootstrap 区间为 `[3.09, 52.64]` bp，条件均值为 0.18 bp，Lift 为 27.24 bp。Development/Validation/Test 事件数为 90/25/21，三阶段 H1 均为正；正式 event-only 的入口是单日事件，不是持续重标。

因此可表述为：V38 提供了较明确的负向转移方向证据，而且在零段切分和实际持仓结构上比早期高频探针更可控；不能表述为每次放量都代表下跌，也不能把 03 的 event-only 标签直接解释成完整交易回测。

#### 6.2 从输入到最终标签的流程

1. 对形成日前的成交量取对数，并在历史窗口内标准化：

   \[
   v_t=\log(1+Volume_t),
   \qquad
   z^{vol}_{t,w}=\frac{v_t-\operatorname{mean}_w(v)}{\operatorname{std}_w(v)}.
   \]

2. 用过去约 `w/4` 天的收盘对数变化确定价格方向：

   \[
   d_{t,w}=\operatorname{sign}\left(\log Close_t-
   \log Close_{t-\max(1,\lfloor w/4\rfloor)}\right).
   \]

3. 形成成交量和价格方向的共振分数：

   \[
   S^{V38}_t=z^{vol}_{t,w}\cdot d_{t,w}.
   \]

4. 对下侧进行定向，使较大的分数支持 `0→-1`，再使用 Development 冻结的 q0.85 入口阈值、零龄、确认和 H03 持仓约束。
5. 只有当基础状态为 `0` 且信号命中时，正式 event-only 标签当天才写成 `-1`；不把一次命中延长成整个负向持仓段。

#### 6.3 为什么最终保留 V38

- 它不是“看到放量就做空”，而是要求成交量异常和价格方向同时提供下侧证据。
- 远端 V1–V2.2 已经暴露了高频脉冲、概率不单调和快速恢复问题；本地筛选进一步加入零段长度、一天段占比、转移纯度和实际持仓结构质量门。
- 本地标准候选网格为每侧 6,144 条，严格筛选后下侧只保留 V38，避免把多个相似逻辑并列包装成多个独立证据。
- V38 有 136 个事件日，Development/Validation/Test 为 90/25/21，三个阶段 H1 均为正；但它仍然测的是事件日方向优势，不等于含成本的完整交易回测。

#### 6.4 汇报时的完整表述

> V38 只在零状态中寻找进入负向状态的事件。它把历史成交量异常做稳健标准化，再与过去价格方向相乘，只有当两者形成下侧共振，并满足 q85、最小零龄 1 天、确认 1 天和 H03 持仓约束时才触发。最终只改变命中当天的 `0→-1`，不是把后续所有零状态都改成负向。当前方向化 O2O H1 为 27.43 bp，三阶段均为正，因此它是四个信号中较清晰的入口候选；但不能把“放量”单独解释成下跌，也不能把 event-only 标签直接称为交易收益。
