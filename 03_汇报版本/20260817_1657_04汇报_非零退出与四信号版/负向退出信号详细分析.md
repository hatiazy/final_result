# 负向退出（-1→0）｜独立详细分析

本报告只分析一个信号，数据来自最新本地重跑的最终上传包口径。所有收益使用 effective-date 网格上的 CSI500 下一交易日开盘到再下一交易日开盘（O2O H1），不把 C2C 当作冻结评价指标。

## 1. 信号定义与结论

- 来源：1545反转预测；冻结规则：`V55 / inductive conformal martingale`。
- 作用：退出负向持仓；要求信号发生时基础状态为 `-1`。
- 事件口径：负向/正向退出只作用于信号当天，后续日期恢复基础三状态。
- 本信号的判断：**有较明确的正向证据**。

全周期有效事件 45 天，覆盖符合条件的基础状态 233 天中的 19.31%；可计算 H1 的事件 45 天。信号日方向化/退出改善均值 **57.35 bp**，bootstrap 95% 区间 **[-0.98, 120.92] bp**；相对所有符合条件基础日均值 -20.18 bp，差值为 **77.53 bp**。

## 6. 最终判断

综合本信号的事件均值、相对条件基础日提升、不同阶段稳定性、前向 1/3/5/10 日路径以及原始段位置，本信号的证据强度判断为：**有较明确的正向证据**。最重要的限制是事件样本不是独立同分布的：连续信号日会集中在同一段行情，且最近一个有效期末日可能没有完整未来 O2O 观察。因此，本报告支持‘是否有描述性改善’的判断，不支持把历史均值解释成未来收益保证。

## 附录：远端尝试、本地尝试与最终构建

### 1. 要解决的具体问题

本信号的目标不是预测“市场下一天一定上涨”，而是在基础状态 `-1` 已经形成时，寻找一个因果时点把方向暴露退出到 0。形成日为 `t`，主评价是：

\[
r^{O2O}_{t,1}=\frac{Open_{t+2}}{Open_{t+1}}-1,
\qquad
g_t=-r^{O2O}_{t,1}.
\]

`g_t` 越大，表示退出当天之后越避免了负向状态的不利路径；相对条件基础日的提升为：

\[
Lift=\operatorname{mean}(g_t\mid exit_t=1)-\operatorname{mean}(g_t\mid B_t=-1).
\]

信号命中时只把当天 `-1` 改成 `0`，下一天重新跟随基础状态；这和把整个负向段提前截断是两个不同的统计问题。

### 2. 远端尝试做过什么

0818 的 1545 远端材料经历了 V1、V2、V2 修复版、V1.1、V1.1 路径进度修正版和 V1.2：

- V1 先坚持连续、可解释的规则证据，负侧重点是尾部压力释放：压力减弱、原方向支持退化、确认后再触发。它有短/中窗口、状态年龄、确认天数、阈值和反弹保护的组合，但不先用黑箱模型，也不把正负两侧塞进同一个控制器。
- V2 与修复版重点检查 O2O 标签、有效日期、候选枚举、Test 隔离和运行输出，解决“代码跑完但口径不一致”的问题。
- V1.1 将“正式通过优先”明确写进筛选。负侧候选 `minus_tail_pri_w10_c2_seq_a3_rv rebound_guard_q35` 只有约 3 个 Test 触发；正侧没有正式通过，所以不能因为联合排序第一就冻结正侧。
- V1.2 加入发动机修复、价格修复、风险确认和 `rebound_guard`。负侧候选 `minus_tail_pre_w5_c2_maj_a2_rvrebound_guard_q65` 的 Test 约 6/30、H1 相对改善约 `+0.006121`，但 H3 和恢复风险仍弱；正侧的 `middle_tail_exhaustion` 形式上有通过候选、但 Test H1/H3 仍不稳定。因此，V1.2 不是当前最终信号，只把它的边界约束和失败经验保留下来。

远端试验真正留下的是“单侧、正式门、Test 隔离、连续证据优先”的筛选框架，而不是某一个早期参数。

### 3. 本地做过什么

本地 1545 线把 V01–V90 放进同一套因果接口，覆盖持续时间、变点、分布变化、路径几何、熵/RQA、单类异常、ROCKET/catch22、共形、概率模型等方法家族。每个版本/侧别有 `9×4×3×3×8=2,592` 个候选，失败版本留在审计记录，不因为方法名称好听就进入最终池。

### 4. V55 最终分数怎样构建

当前代码适配首先将负向收益转正向化，再取三日因果均值作为证据：

\[
a_t=\frac{1}{3}\sum_{j=0}^{2}\left[-r^{close}_{t-j}\right].
\]

在 Development 且满足负向基础状态、标签已经成熟的样本上形成校准集合 `A_D`。对当前证据计算尾部 conformal p-value：

\[
p_t=\frac{1+\sum_{a\in A_D}\mathbf{1}(|a|\ge|a_t|)}{|A_D|+1}.
\]

给定预注册 betting factor `β`，构成单步下注因子和状态段内累计分数：

\[
b_t=1+\beta\max(0,0.5-p_t),
\qquad
S_t=\sum_{u\in\text{当前基础状态段}}\log b_u.
\]

它的含义是：当前证据越不像 Development 中的“正常延续样本”，`p_t` 越低，累计退出证据越高。校准集固定在 Development，不允许 Validation/Test 重新校准。

最终冻结为：

```text
V55 / inductive_conformal_martingale
score_02_q68_a1_c2_cd0
β=0.50；阈值分位=68%；最小状态年龄=1；确认=2天；冷却=0天
```

### 5. 为什么选它，以及怎样表述结果

V55 在当前 03 口径下有 45 个退出日、条件负向日 233 个，方向化 O2O H1 为 57.35 bp，95% bootstrap 区间为 `[-0.98, 120.92]` bp，条件基础均值为 -20.18 bp，Lift 为 77.53 bp。Development、Validation、Test 的事件数为 26/11/8；Test 为正，但只有 8 个事件日。

因此可以说：V55 对负向状态退出有较明确的描述性正向证据，且本地/远端的最终候选和五列结果已经对齐；不能说它已经证明未来稳定盈利，也不能把 bootstrap 区间或少量 Test 事件当成确定性保证。连续信号日、同一状态段内重复触发和 2026-08-17 未成熟尾行都必须按原报告限制解释。

#### 6.2 从输入到最终标签的流程

1. 在每个形成日只读取截至当天的收盘、状态和历史收益，先把负向收益转成退出目标方向。
2. 计算三日证据：

   \[
   a_t=\frac{1}{3}\sum_{j=0}^{2}\left[-r^{close}_{t-j}\right].
   \]

3. 用 Development 中已经固定的校准集合 `A_D` 计算尾部 conformal p-value：

   \[
   p_t=\frac{1+\sum_{a\in A_D}\mathbf{1}(|a|\ge |a_t|)}{|A_D|+1}.
   \]

4. 使用预注册的 `β=0.50` 累加当前负向状态段内的退出证据：

   \[
   b_t=1+\beta\max(0,0.5-p_t),
   \qquad
   S_t=\sum_{u\in\text{当前状态段}}\log b_u.
   \]

5. 以 Development 冻结的 q68 分位作为候选阈值，再应用最小年龄、确认日和冷却参数，形成 `entry/exit_signal`。
6. 只有当基础状态确实为 `-1` 时，才在该形成日输出 `0`；如果基础状态不匹配，即使分数达到阈值，也不伪造退出标签。

#### 6.3 为什么最终保留 V55

- 它把“负向状态是否仍在延续”转化为“当前方向化证据是否离开历史正常延续分布”，与退出问题相匹配。
- 它不依赖 Test 重新校准，也不把 Validation 之后的信息倒灌回分数。
- 它在本地完整候选池中通过 Development+Validation 的冻结流程，且远端与本地最终五列结果逐日对齐。
- 它的证据仍然是小样本描述性证据：45 个事件日、Test 仅 8 个事件日，不能说已经证明未来稳定盈利。

#### 6.4 汇报时的完整表述

> V55 不是预测市场下一天一定上涨，而是在负向状态已经形成后，识别负向延续证据减弱的退出时点。它用 Development 固定的 conformal 校准集构造 betting/martingale 累计分数，在 q68、最小年龄 1 天、确认 2 天和零冷却的参数下冻结。最终只改变命中当天的 `-1→0`，Test 不参与选参。当前全周期方向化 O2O H1 为 57.35 bp，但事件数和 Test 样本都较少，因此应定位为有价值的候选退出信号，而不是已完成生产验证的规则。
