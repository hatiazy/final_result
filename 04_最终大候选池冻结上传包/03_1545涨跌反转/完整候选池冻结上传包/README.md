# 1545 反转预测：新三状态口径双侧全量合成公司包

这是一个只含可执行逻辑的公司端重选包。负向和正向退出是两个独立候选池，允许使用不同版本和不同核心逻辑。包内 1545 基准状态由现货数据重算，不读取外部九状态文件或期货文件。

## 最终候选池

- `-1→0`：V04、V49、V50、V55、V57、V76，共 6 × 2,592 = **15,552** 条原始候选。V51 在事件日口径审计中使负向段胜率下降，故不再进入最终负向池；
- `1→0`：V49、V70、V80，共 3 × 2,592 = **7,776** 条原始候选。

入池后放入的是每个版本/侧别完整的 2,592 条候选网格，而不是本机已经选出的一个参数。包内不携带本地阈值、冻结 JSON 或 Test 结果。公司端重新计算每个候选的 Development 阈值，在各自侧别全量池内用 Development+Validation 冻结一个非退化 Top1，冻结后才展示 Test。

本地研究阶段的入池条件是：版内 Development+Validation 正式通过、不是纯 `base_state + state_age` 年龄基线、冻结后 Test 至少 8 个事件、Test H1 至少 20bp、Test H3 为正，且入选版内轨迹在入选名单中不重复。除此之外，退出调整后的持仓段和收益分布还会在检查 Notebook 中单独审计，但不回写到候选筛选或公司端冻结。

## 现货重算的八状态口径

`src/common/spot_eight_state.py` 按 `spot_eight_state_config.json` 的冻结 family、参数、变换和组合方式，因果重算八个现货状态：位置修复、反转压力、尾部压力/波动切换、趋势、路径脆弱、跳空/日内承接、过热、量价。量价组合保留冻结定义“上涨确认均值与下跌放量均值再取均值”。因果滚动分位使用 504 日窗口、至少 252 个历史观察；没有第九个流动性状态，也没有任何期货/OI/基差输入。

## 远端唯一输入

包默认读取唯一远端现货文件：

```text
1545_SPOT_PATH=/home/hzy/cta/IC数据更新*最终固化版/现货最终版/CSI500_SPOT_md_eod_raw*最终版.parquet
```

通配路径必须唯一匹配一个文件。现货表应包含 `index_code, trade_dt, crncy_code, preclose, open, high, low, close, change, pctchange, volume, amount, data_source, month`；包实际使用 `index_code, trade_dt, preclose, open, high, low, close, volume, amount`，其余列不参与计算。输入会审计日期范围、八状态重算缺失值、`-1/0/1` 状态集合和禁用字段。

形成日是 `t` 收盘，`effective_date` 是下一实际现货交易日开盘，O2O H1 是第二实际现货交易日开盘；已存在下一行时完全按实际交易日对齐，不会把信号整体后移。若输入最后一条形成日尚无下一行，导出层只用 `BDay(1)` 生成待执行占位日期，待下一次数据更新后会被实际交易日覆盖。

## Notebook

- `01_负向退出_-1到0.ipynb`：重建负向大池，展示每个入池逻辑自己的 DV-Top1、Full cycle、冻结后 Test，然后进行公司大池 DV 冻结和最终 Test。
- `02_正向退出_1到0.ipynb`：正向侧同上，侧别独立。
- `03_生成最终五列三状态信号.ipynb`：重新冻结两侧最终 Top1，输出严格五列 `date`、`three_state`、`minus_exit_signal`、`plus_exit_signal`、`final_three_state` CSV。`final_three_state` 只在实际退出信号日把对应 `-1/+1` 改成 `0`，下一交易日恢复原始三状态，不做持续压制。
- `04_冻结退出持仓时间审计.ipynb`：读取 03 号 CSV，比较原始/最终三状态的天数、占比、持仓段、退出日；另外按原始/调整后的 `-1/0/1` 分别展示持仓段胜率、正收益段数量、3%/5% 大额正收益尾部、方向对齐段收益分布、**不做方向对齐的原始指数段收益分布**、日 O2O 收益分布、1 日和 ≤3 日碎片段比例，并绘制两种状态曲线和退出日曲线。对负向 `-1`，原始指数上涨段及其 q95/最大值是专门的“不利尾部”观察，并额外给出一张紧凑的调整前后对照表；退出质量标志明确列出“段胜率是否提高、正收益段是否减少、大额正收益尾部是否缩短、负收益尾部是否改善”。Notebook 最后一节再给出全周期/分阶段 H1 O2O 预测准确性、均值/中位数/分位数、段胜率与碎片化综合仪表盘，并在指数曲线上用点形状区分两侧、用绿色/红色区分退出后 O2O 有利或不利，逐点标出原始 O2O(bp)。所有这些是冻结后的描述性检查，不参与筛选。
- `05_比较冻结三状态基准.ipynb`：可选的对照审计，只比较生成 CSV 与 `/home/hzy/cta/三状态冻结/IC_1545_three_state_and_downside_warning.csv` 的 `date/three_state`，不参与冻结。若远端没有该基准文件，不运行这一格即可，不影响 01–04。

运行 01/02 时会逐阶段打印现货读取、八状态重算、逐版本候选、版内 DV-Top1、冻结后版内 Test、公司大池 DV 冻结和最终诊断；最后一格集中输出最终冻结参数、全周期、Development、Validation、Test 和 Test 年度拆分，适合截图回传。

## 防退化审计

`src/pool_runner.py` 内置固定保护：若候选在 DV 上完全等于 `base_state + state_age >= age`，即使形式上通过，也不会成为版内或公司侧最终 Top1；完整原始网格仍保留在池内以便审计。公司端最终 Top1 的字段明确标记 `test_used_for_selection=False`。

## 包内容边界

包内只有五个 Notebook、必要 `src`、八状态冻结配方、版本/侧别注册表、持仓段审计模块、README、依赖文件和 `PACKAGE_MANIFEST.json`。不包含本机候选结果、Test 结果表、阈值、冻结 JSON、模型文件、数据、缓存、截图、凭据或本机绝对路径。`PACKAGE_MANIFEST.json` 只记录池成员和输入边界。
