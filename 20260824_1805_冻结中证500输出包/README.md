# 20260824_1805｜冻结中证500输出包

这是一个独立的远端运行包，包含冻结生产源代码、03—06 分析 Notebook，并新增 07 作为“远端结果 vs 本地结果”专门一致性检查。冻结信号逻辑保持不变，只把包根目录、现货输入和前序输出改成远端绝对路径；06 的诊断面板也固定从同一份现货重建，不读取外部旧面板。

远端运行时，生产计算只需要一份中证500原始现货日频文件；本地结果已经作为 `本地结果对照/` 放入包内，不需要再从本地电脑读取，也不需要读取远端三状态文件才能生成信号。

## 包内入口

- `03_含持有期零段反转八列表.ipynb`：直接调用包内冻结生产源代码生成事件八列，再展开 V38/V57 的冻结持有路径，得到每日含持有期精简八列；这是日常唯一需要运行的信号 Notebook；
- `04_O2O加算收益与持有段计数分析.ipynb`：读取 03，生成 O2O 加算收益、净值、风险和持有段统计；同时输出四个反转全部加入后的最终三状态持有期分布与碎片诊断，并保留“基础三状态 + 仅 `0→-1`/`0→+1` 持有路径”的独立分析；
- `05_逐年分析与2026表现解释.ipynb`：读取 04，生成逐年、训练/验证/测试期及 2026 拆解；
- `06_历史相似行情与机制分解分析.ipynb`：读取同一份远端现货、03 和 04 的远端输出，生成历史相似行情及机制分析；新增老师原图同时间范围的 2023 年至最新完整三曲线 O2O 图，以及三个红色0区间的逐段 O2O 复盘图，固定复盘 2023-11-01—2024-01-15、2024-04-15—2024-09-15、2025-03-01—2025-07-15。06 不接受 `PANEL_PATH` 作为隐含输入，内部 1545 面板始终由当前 `COMPANY_SPOT_PATH` 重建；老师红框两张表写入 `runtime_outputs_06_mechanism/tables/`，与展示单元格读取路径一致；
- `07_远端与本地结果一致性检查.ipynb`：将远端本次运行的 01、03、04、05、06 表格与包内 `本地结果对照/` 逐表、逐行、逐列比较，输出明确的 `success` 结论。

生产冻结代码在 `src/` 和 `packages/` 中；不包含候选扫描、成交记录、未来评价记录或每日现货快照。

## 输出列和日期口径

01、03 的精简八列固定为：

```text
实际执行日、三状态、+1反转、-1反转、0转-1、0转+1、大涨、大跌
```

每一行统一遵循：

```text
t 日收盘形成信号 → 下一实际交易日 t+1 开盘执行
```

最新形成日的信号值由最新现货收盘前可获得的数据真实计算，不用 0 占位；如果最新执行日尚无下一日开盘价，只影响收益评价，不影响信号输出。

## 运行前冻结审查结论（截至 2026-08-25 执行日）

本地参考的现货最大日期是 `2026-08-24`，因此本地事件八列和含持有期八列的最后执行日是 `2026-08-25`。最后一行的含义是：`2026-08-24` 收盘形成信号，映射到 `2026-08-25` 开盘执行；它不是用 0825 收盘价回填出来的占位行。对应的本地含持有期明细最后一行也是 `形成日=2026-08-24、实际执行日=2026-08-25`。

冻结隔离已按生产入口检查：

- Development（开发/训练）用于因果阈值校准、模型拟合和初始候选评价；
- Validation（验证）用于候选排序、跨阶段质量门和最终 Top1 冻结；
- Test（测试）在冻结之后才读取，只作外样本观察，不参与阈值、候选、持有包或 Top1 回写；
- 运行时只读取一份现货，最新形成日不需要未来 O2O 标签，也不会因未来标签缺失而把信号填成 0；
- 运行时的 `test_used_for_selection`、`candidate_rebuild`、`reselection_performed` 等审计字段应保持为 `false`。

因此，当前冻结逻辑不存在已发现的未来数据泄露问题。但“通过冻结门槛”不等于四个信号在三个阶段都同样强。历史冻结审计中的事件 H1 指标如下（H1 是信号触发后下一交易日的方向化 O2O，不是筛选时唯一使用的分数）：

| 信号 | Development | Validation | Test（冻结后观察） | 定性 |
|---|---:|---:|---:|---|
| V55，`-1→0` | 26 / +40.55bp / 65.38% | 11 / +98.46bp / 45.45% | 8 / +55.41bp / 75.00% | 可运行，但验证样本少 |
| V80，`+1→0` | 19 / +53.53bp / 57.89% | 10 / +105.53bp / 60.00% | 33 / +25.45bp / 45.45% | 通过冻结门槛，测试方向命中偏弱 |
| V38，`0→-1` | 90 / +22.69bp / 55.56% | 25 / +13.30bp / 56.00% | 21 / +64.56bp / 57.14% | 四个中外样本稳定性最好 |
| V57，`0→+1` | 51 / +12.31bp / 52.94% | 20 / +42.74bp / 50.00% | 15 / +8.95bp / 53.33% | 已冻结可运行，但证据较弱；Test Rank IC 为 -0.340 |

正确表述是：四个信号均通过了预先登记的开发/验证冻结门槛，V38的跨阶段和测试表现最稳；V55、V80可以作为稀疏退出信号运行；V57仍应视为弱证据信号。不能把四个信号宣传成测试集都很强，也不能用测试结果反过来改参数。基础三状态在开发/验证满足状态语义顺序，但测试阶段样本较少，0 状态经济含义有退化迹象，因此也应称为“冻结的可解释基线”，而不是测试集已完全验证。
